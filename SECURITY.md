# Security Policy

## Supported versions

Akshara is pre-1.0 and currently provides security fixes for the latest
released version only. Upgrade to the latest release before reporting an issue
that may already be fixed.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
[nikhil25803@gmail.com](mailto:nikhil25803@gmail.com) with:

- the affected version or commit;
- the impact and affected component;
- reproduction steps or a proof of concept; and
- any suggested mitigation, if known.

Do not include real API keys or personal documents. The maintainer will confirm
receipt, investigate the report, and coordinate disclosure and remediation as
appropriate.
